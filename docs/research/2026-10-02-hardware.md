# Hardware items — research of 2026-10-02

> **Purpose — so the 0.2.0 hardware items (NVIDIA, sound firmware,
> Broadcom Wi-Fi) cite where their rules came from.** A dated record: it
> is not updated. A newer finding goes in a newer file.

Read-only research on the author's Tumbleweed (AMD GPU, Secure Boot off)
plus repository metadata and upstream sources. en.opensuse.org refused
automated reads; claims from it are search snippets only and say so.

## NVIDIA driver

- **Detect without root:** `/sys/bus/pci/devices/*` with `vendor`
  `0x10de` and `class` `0x0300…` or `0x0302…`.
- **Which driver, by device id** (from the NVIDIA repository's
  `primary.xml`, download.nvidia.com/opensuse/tumbleweed):
  `nvidia-open-driver-G07-signed-kmp-meta` (595.x) supplements ids
  0x1E02–0x31C3 (Turing and newer); `nvidia-driver-G06-kmp-meta`
  (proprietary) ids 0x1340–0x1DF6 (Maxwell to Volta). An id in neither
  gets no package (nouveau). NVIDIA's README 595.99.02
  (`kernel_open.html`) recommends the open modules wherever supported.
- **Trap:** `nvidia-open-driver-G06-signed-kmp-meta` shares 284 of 286
  ids with G07, so `zypper install-new-recommends` may pick either.
  Install the meta package by name.
- **Repository:** Tumbleweed and Slowroll
  `https://download.nvidia.com/opensuse/tumbleweed`; Leap 16
  `https://download.nvidia.com/opensuse/leap/16.0/` (repomd.xml 200).
  doc.opensuse.org's install_proprietary page is stale (G06, 515 series).
- **Leap 16.0** installs the open driver and its repository by default
  on supported GPUs (release notes § 2.5), so expect "done" there.
- **Done:** the meta package installed (`rpm -q`); `/sys/module/nvidia`
  present.
- **Secure Boot, without root:** `mokutil --sb-state` works as a normal
  user; or the last byte of
  `/sys/firmware/efi/efivars/SecureBoot-8be4df61-93ca-11d2-aa0d-00e098032b8c`
  (mode 0644) is 01 when on. The proprietary G06 driver builds on install
  and needs a MOK enrolment at the next boot (SDB:NVIDIA_drivers, search
  snippet). Whether the `-signed` open driver needs one is unverified.

## Sound firmware (sof-firmware)

- **Need:** an Intel audio device (vendor `0x8086`) bound to a
  `sof-audio-pci-intel-*` driver rather than `snd_hda_intel`; class alone
  is not decisive (kernel `sound/hda/core/intel-dsp-config.c`). The
  driver name is inferred from the module names, not checked.
- `sof-firmware` carries modalias Supplements for its hardware, so the
  installer pulls it in where it matches; it is not installed otherwise
  (`rpm -q sof-firmware` on the author's machine: not installed).
- **Done:** `rpm -q sof-firmware`. **Install:** `zypper in sof-firmware`
  (Tumbleweed OSS; Leap 16 OSS `sof-firmware-2025.05`).

## Broadcom Wi-Fi (broadcom-wl)

- **Chips with no open driver** (wiki.debian.org/wl): 14e4:4358, 4359,
  4365, 43b1, 43a0, 4360. Detect: vendor `0x14e4`, class `0x0280…`,
  device id in that list.
- **Where the package is:** Tumbleweed and Slowroll — openSUSE's own
  NON-OSS repository, not Packman. Leap 16.0 — Packman Essentials only
  (`broadcom-wl-kmp-default`, with `broadcom-wl-ueficert`).
- **Trap:** the Tumbleweed kmp supplements every Broadcom Wi-Fi chip, so
  `zypper install-new-recommends` would install wl where an open driver
  works. Gate on the id list.
- **Done:** `/sys/module/wl` present (inferred).
